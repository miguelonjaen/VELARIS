# SmartShip Design System (SSDS)

## Objetivo

Crear un sistema gráfico vectorial propio para SmartShip-PRO.

No se utilizarán iconos descargados de terceros.

Todos los elementos estarán diseñados específicamente para navegación profesional.

---

## Filosofía

- SVG puro
- Componentes reutilizables
- Escalado perfecto
- Animaciones suaves
- Alto rendimiento
- Integración React + Leaflet
